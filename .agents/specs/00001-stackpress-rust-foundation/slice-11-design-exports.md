# Slice 11 complete named-export ledger

Status: Draft / Not Frozen. Extracted from every src/**/*.ts declaration in the [43-file inventory](slice-11-design-inventory.md). Names retain source spelling, including aliases/typos, rather than silently normalizing or expanding root exports. Each row inherits the disposition and reason below. An exported name does not claim an identical Rust function/class already exists.

## Disposition families

| Family | Now / later / intentionally not ported and target |
| --- | --- |
| api | Now reuse framework-api config/models/pages/views/source errors; JS type/exception names not separately ported. |
| client | Now bridge CompiledClient/catalog + existing schema/revisions/config owners. JS module import/type intersections/constructor names not ported. |
| language | Now bridge native source cookie/prefix service and reuse Leptos/pure registry; static JS Language constructor/interface not ported. |
| lib | Now reuse root/lib/server/CLI/Idea/SQL contracts. Exact JS callable/readonly wrappers, Node FS/stream/Reflection/type aliases not ported; accepted owned Rust APIs replace their representations. |
| schema | Now reuse framework-schema/codegen/providers; mutation/import/class/token/interface JS representations and helper aliases not duplicated. |
| server | Now reuse lib/server/CLI/HTTP + command bridge. JS Node/WHATWG handles/stream conversion/module loader representations not ported. WHATWG host bridge is named S11-WHATWG follow-up. |
| session | Now reuse source-parity session/auth/profile/permissions/storage/views; JS constructor/variadic/callable type signatures not ported. |
| sql | Now reuse SQL/framework-SQL and native backends plus operator/catalog bridge. PGlite runtime/connector is later S11-PGLITE; driver JS types/connect wrappers are not exported as Rust APIs. |
| view | Now reuse Leptos/view/admin public UI and native provider bridge; React hooks/props/classes and Reactus/Vite/VFS toolchain identifiers not ported. |
| events / scripts | Now explicit delegated-command bridges; scripts omits query. No copied second implementations or claim that registration executes commands. |
| index / types | Now facade fan-out to the families above; exact hundreds of flat JS aliases not ported. Source alias distinctions retained in documentation and qualified Rust modules. |
| plugin | Now source-order aggregate registration. |
| unocss | Intentionally not ported as JS preset; current component/app CSS remains. No source rule correction or default style injection. |

## Root/subpath distinctions

src/index.ts exports Session as the JWT identity and types its foundation cookie Session as ServerSession; API Session is exposed as ApplicationSession and the Reactus Builder/Document/Server names are prefixed. src/types.ts additionally includes ApiType; root index does not list it. client/index.ts exposes Revisions; sql/index.ts exposes Migrations; schema/index.ts exposes StackpressSchemaException; view/client exposes the admin browser helpers. Do not invent those as flat root exports merely because a submodule has them.

TypeScript typesVersions duplicates routing declarations, not behavior. The advertised paths are recorded in provenance together with all require/import targets. The proposed Rust surface uses qualified crate modules to prevent these collisions without changing the original libraries' behavior.
