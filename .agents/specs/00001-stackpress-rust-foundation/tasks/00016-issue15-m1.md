Locale-only saves preserve unset and never persist the OS color. Native preferences load before CSR and sample once only when unset.

Unset SSR uses the classic same-origin pre-paint asset; explicit saved choices have no pending marker or executable asset dependency. No-JS, denied or missing bootstrap leaves unset readable Light; saved Dark stays Dark. The asset has no storage, fetch or change listener. Checked nonce formatting is separately tested; browser CSP-denial cases use the real example.
- Updated Profile, preferences, gallery, review-preview, stream and all PageAssets/snapshot constructors. Profile hydration adopts early native draft text independently of the last acknowledged query/results. Native filenames/revision, deadlines, cancellation, authoritative admission and failure semantics remain in their original owners.
- Added the [Rust API migration note](../../../../crates/framework/framework-view/docs/migration-issue15.md) and updated affected view/UI/example references. Historical Lane B/M0 receipts retain their claims; relocation/retirement notes repair four links broken by the approved removals.
