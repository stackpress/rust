## Limits as built

Defaults: 64 SSE and 64 WS slots, including pending publication/handoff; sum must leave ordinary global HTTP capacity. Session age <=1 hour. SSE event/cursor/name 64 KiB/1 KiB/256 bytes, session 64 MiB including comments, heartbeat/write idle 15/30 s. Optional SSE channel <=16 events/1 MiB with immediate full errors. WS message/frame <=64 KiB, each queue <=16 messages/1 MiB, buffers 16 KiB read/write and 256 KiB maximum; ping/pong/idle/send/close 20/10/60/10/5 s. Stop finishes current SSE event then EOF; WS Close(1001), bounded by shared grace. RAII permits outlive cloned response descriptors and return at exclusive native-owner drop.

Browser latest retention <=64 KiB, EventSource names <=32 and 256 bytes, cursor <=1 KiB; WS bufferedAmount ceiling 256 KiB. Reconnect defaults off, <=5 attempts at 1/2/4/8/16 s, no resend. Native SSR opens nothing. DOM/native browser allocation is outside Rust retention accounting; browser adapters require real browser proof, not a native coverage claim.
