### Rust mechanics necessities

- Typed host config is package-owned; OAuth reads an optional pages::Environment service carrying the app's view/brand objects rather than claiming other plugins' config sections. The example explicitly maps those inputs. Missing service uses source defaults. The clock is a Send+Sync borrowed-call provider, not ambient mutable identity.
- Public session identity stays entirely behind its registrar, configured cookie and me event. Same Request is borrowed into me; fresh object resolutions own new Request/Response values, except application-detail intentionally shares the current Response. No session/lib/server changes or missing public-surface gap.
- In-process Timestamp supplies source Date input. API SQL already emits canonical ISO Date wire strings, so token decodes only that spelling through the existing owner codec and explicitly serializes rich profile Dates at the JSON boundary. Direct non-native consumers supply JSON-compatible profile fields. Invalid Date / native range / unsupported native String conversions return explicit mechanics errors; no lifetime or destination policy is substituted.
- Existing reqwest::Url reexports the approved URL library. Only a detached query carrier is normalized: redirect itself is split/concatenated verbatim. Controls that URL.set_query would discard are escaped before decoding; URLSearchParams duplicate/set/form-encoding semantics are retained. The inherited validated Location header still rejects impossible native framing.

### Risk proofs and limits

Concurrent real JWT callers keep distinct profile IDs and persisted rows. A me observer reenters real application SQL, then synchronizes both callers at a barrier; no lock spans await. A parent process gives five seconds readiness and ten seconds completion, then kills/reaps. The existing deliberately blocked-child proof still checks the supervisor. Cancellation polls nested session-create to pending, drops the owning future and proves its Drop guard runs; earlier shared application output remains and no worker is detached. Already completed SQL inserts are not rolled back by a later redirect/response error.

Accepted source responsibilities remain parity behavior: caller destination/state, request-supplied model fields/scopes/secrets, any nonempty token-page app secret, repeated exchange and plaintext credential output. Selected model events own their existing row selection; API adds no extra authorization or public-exposure policy. No real HTTP listener/network, browser/Leptos UI, WASM/installed acceptance or live PostgreSQL/MySQL claim. Existing M1 backend limitations apply. No commits, pushes, installs, GitHub writes or other-agent messages.
