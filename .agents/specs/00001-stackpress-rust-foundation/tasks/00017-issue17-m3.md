**HEAD decision: option (a).** Added [render::document_shell](../../../../crates/leptos/src/render.rs), a pure helper taking trusted HTML-attribute, head and body fragments. It emits the generic document frame and always places `<!--HEAD-->` at the end of its head. It has no page, asset, protocol or persistence concepts. The trusted-fragment contract explicitly requires escaping untrusted interpolations and forbids closing enclosing elements. Empty/attribute framing has exact unit/Rustdoc checks.

Construction supplies the missing marker in release as well as debug builds. Documentation alone had already left the consumer exposed to this trap; a debug-only check would miss release and introduce rejection/panic behavior for existing custom shells, including metadata-free ones. This small additive helper is the narrowest reliable option. View keeps its existing framing literals and does not call it.

The independent native document now uses the helper. Its **eight actual documents are byte-identical to accepted M2 artifacts**, and all **16** base/helper hydrate/CSR browser cases pass, including metadata/title and hydration identity. ## Round 4 — safety and soundness

**Finding restored:** the exact two-slot bridge assertion is now at the generic **public** renderer/writer seam in [render_seams.rs](../../../../crates/leptos/tests/render_seams.rs), independently supervised by the external watchdog. A six-item immediately-ready source counts actual polls; the first frame schedules a worker-local observation after that producer poll yields. On the single-thread LocalSet, source/frame work remains ready until capacity parks the producer. The host consumes the prefix only, so no body slot is freed before observation. Both the observed count and current source count must be **exactly 2**; before first demand the count is zero.

This uses public source/framing callbacks, no private channel inspection or production diagnostic hook. There is no timed negative assertion. Each run repeats **16 drain and 16 full-queue disconnect cases**; drain reaches all six items and fused EOF, while drop must synchronously clean/reap the worker, verified by a captured Weak reference. An independent ten-second parent deadline kills/reaps a hung child and requires its completion marker. The original view-level six-Suspense progress fixture remains, with an observation barrier replacing its 30 ms sleep; exact channel capacity is tested separately from upstream HTML fragment grouping.

The public seam also compile-checks the staging future, prepared/owned output and byte body as `Send` while the factory constructs local `Rc` view state. Existing watchdogs recheck pre-demand drop, pending-resource cancellation, panic/unwind, Owner restoration, timeout, cumulative replay/output admission, late failures and successful EOF. Production validators, ImageSource checks and navigation policies are unchanged.

The **single G41 differential table** still runs against both independently owned location validators and HTML/script escapers in the normal view `leptos` integration test. It covers valid/malformed percent escapes, dot aliases, Unicode, queries, exact length limits, encoded-byte preservation, script terminators and Unicode separators; added a mixed-case script terminator. A minimum-feature `leptos` run proves the guard does not depend on SSR. `ImageSource` retains its strict local/raster/suffix/dimension/byte checks; broader `safe_href` remains separate.

Stream documentation now states the existing caller-owned Head boundary: pinned upstream Title needs an HTML-escaping formatter for untrusted title text. A hostile-title public-seam test supplies that formatter and proves inert prefix output. View already installs it; kernel defaults and page output are unchanged. CSP nonce/status/replay/browser recovery cases pass. Cooperative cancellation still cannot preempt arbitrary nonyielding trusted work or a blocking/panicking destructor.
