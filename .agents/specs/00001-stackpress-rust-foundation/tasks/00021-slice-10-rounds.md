- Added views/document.rs for synchronous Leptos owner disposal and the existing unset-theme bootstrap. Consent and management retain their separate templates, title/language/seed attributes and head ordering. Reactive state is disposed before owned HTML enters a Send response future; errors retain the same cleanup order.
- Kept StoreQuery API-local deliberately. API q is Option<Value>, retaining []/{}/Boolean/number/Date truthiness and interpolation; session StoreQuery q is Option<String> and searches Profile. Re-exporting it would change this public input contract. A common generic carrier would require a separately owned shared change without removing the distinct query engines. Existing Record/DataMap and column codecs remain reused.
