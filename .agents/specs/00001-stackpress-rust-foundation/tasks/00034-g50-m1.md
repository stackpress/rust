## Delivered contract

- `stackpress_framework_schema::codegen::emit_source_contracts(&SourceGraph, &mut OutputPlan)`
  uses separate structural templates, retains complete metadata, and preflights unsupported
  declarations before contributing files. Typed emitters and their templates are unchanged.
- `SourceGraph::catalog()` emits owning/reverse edges, exact query selectors and scalar
  wildcard expansions. It keeps external links unresolved; session-only output creates
  Profile/Auth only, with no hidden Application/Session tables.
- `source::{SourceColumn,SourceRecordSchema}` delegate source codecs and expose metadata-driven
  defaults, filter/populate, assertions and ordered conversion. Literal defaults follow the
  original getter's `unserialize`; provider results return directly. Native Dates, omitted
  members, explicit null, false, UTF-16 lengths and insertion order retain their distinctions.
- `codegen::source_definitions()` retains source role aliases/arguments and fixed URL/password
  input types. All 107 bindings are metadata-only (`available=false`); no renderer, DTO
  publication, route policy, app IO or plugin registration is selected by generation.
- `stackpress-framework-models` contains officially generated `ProfileSchema`, `AuthSchema`,
  `ApplicationSchema`, `SessionSchema` and their catalog. Runtime dependencies are lower
  schema mechanics only; Idea dependencies are optional `generate` build-host edges.
- `framework-models-generate` uses the same public composer/emitter/writer. `--check` writes
  nothing and rejects source drift or manual edits. Every managed default file was produced
  by this tool, never hand-edited. `--input` supports a single app entry with the package
  catalog; auxiliary relative app files need an application-owned loader.
- Generated code uses `stackpress_framework_schema::source::__private::serde_json`.
  The extended disposable app depends on the schema runtime alone, without a direct
  serde_json dependency. The new package uses serde_json only as a dev-dependency.

M1 completes schema/column/default/codec and presentation/relation/query **metadata** emission
for every shipped construct. It does not implement stores/actions/events/DDL execution (M2),
or default-family plugin/CompiledClient wiring and concrete UI emission (M3). No core override
is repaired. The legacy public `source::Column` state, session/API re-exports and behavior are
unchanged; only newly introduced M1 wrapper codec/state members were made private in round 2.
