## Implementation notes

- G41 removal is complete: no old package, workspace member, facade aliases/features or lock entry; no shim. Facade exports `stackpress::leptos` plus explicit `framework-view-leptos*` adapters. All active manifests, imports, generated template strings, generated outputs, examples, proof drivers and documentation paths migrate.
- L owns generic components/state/language/resources/rich/format/edit, checked images, replay, Owner management, synchronous/buffered-async kernels and supervised streams. It has no normal dependency on another Stackpress crate. Native kernels accept caller-owned factories, limits, errors and framing; they do not acquire application state.
- V owns `leptos::{render,async_render,stream,routing,replay,presentation}`. Old application renderer names and page result/error types are retained at the new paths. Snapshots, mounts, assets, theme policy, document framing, replay templates, status/recovery and HTTP semantics remain in V. Default V acquires no Leptos or server dependency. Upstream macro dependencies are optional and pinned identically.
- Sync staging keeps fresh Owners and eager Head ownership. Buffered async keeps Owner/shared context until body/replay/reactive Head completion, restoring the previous Owner on every poll. Stream keeps its single worker/current-thread runtime/LocalSet, demand gate, two-slot bridge, reserve-before-poll backpressure, aggregate framed budgets, deadline, cancellation and join-on-drop.
- G41 safety is independently owned: L has `navigation::LocalLocation`/`LocationError` and local HTML/script escaping; V retains `PublicLocation` and its own escaping. `ImageSource` retains strict local admission, raster/suffix/dimension/byte checks; broader `safe_href` is unchanged. A normal V integration test runs the same 35 local-location cases and six escaping cases against both implementations, plus pinned exact terminator/HTML outputs. Preferences also test Light/Dark mapping and preserved absence.
- G39/G40 first paint, null saved theme, no-JS Light, acknowledgement/draft/root preservation and the one-shot asset remain unchanged. CSS, icons, SVGs/licenses/notices and stream status JavaScript are byte-identical to the old package.
- Admin depends on L; generation emits new generic paths. Official default/formatted generators ran current checks and empty repeat generations. Plugin-selected/disabled generation is tested in disposable workspaces overlaid with current source. Profile generation remains current/idempotent.
- Protocol tests move to V; generic tests move to L. Added production seam tests cover Send migration, fallible errors, Owner cleanup and local `Rc` stream factories. A zero fragment budget is explicitly rejected by the new generic API. Existing protocol admission/error precedence remains pinned.
