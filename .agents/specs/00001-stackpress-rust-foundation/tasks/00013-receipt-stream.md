## Implemented contract

[The opt-in renderer](../../../../crates/framework/framework-ui/src/stream.rs) uses `framework-ui/stream` (includes SSR); the existing synchronous and buffered async renderers remain defaults. A checked owned snapshot/factory crosses into a private current-thread Tokio runtime/LocalSet. No local Leptos view/Owner crosses back: staging returns owned frozen Head/opening/status, then an exclusive Send stream. Factories remain Send/Sync; their view is constructed locally. The server handler installs this stream through the existing `HttpResponseExt::stream`, applies status once, and completes the normal G12/G17 response lifecycle before first body demand.

A two-slot Tokio channel is the bridge. Capacity is reserved before polling another in-order HTML fragment. Ready Resource data is emitted alongside fragments as escaped inert replay templates. [The request-local SharedContext adapter](../../../../crates/framework/framework-ui/src/stream_replay.rs) delegates pinned identity/ErrorBoundary/blocking-resource semantics, owns serialization futures separately and polls them without a queue lock held. Aggregate replay rejects duplicate/out-of-range identities, more than 64 resources, and logical byte excess. Aggregate HTML and per-chunk ceilings include escaped replay plus a reserved fixed failure marker. Blocking Resources delay staging; ordinary Suspense does not. Later Head changes are not promised.

UI `stream::StreamLimits` defaults to `max_chunk_bytes = 64 KiB`, `render_timeout = 30 s`; zero and unrepresentable deadlines are invalid, never unlimited. PageContract supplies lowerable total HTML/snapshot limits. The host's own StreamLimits/NetworkLimits can impose tighter delivery deadlines. Hosts must bound request admission; this implementation uses one owned runtime thread per streamed page.

Stream Drop closes the receiver, signals cancellation, joins the worker and tears down its LocalSet/runtime, including upstream spawned Resource/effect work. Root cleanup aborts guarded loaders and clears serialization/deferred queues to break context/Resource cycles. Staging cancellation has the same join guard. There is no custom global executor, global panic hook, unstable Tokio API, unsafe Send assertion or detached render thread. Cooperative, bounded, yielding loaders are required; CPU-bound work, blocking destructors, panic-abort and rollback of side effects are outside this guarantee.

Precommit failures use a fresh safe response. After commit, checked failures send a fixed inert failure template and one safe typed error, with no status rewrite, retry, completion marker or error lifecycle reentry. A precommitted visible recovery notice and checked reload link remain available if the transport cannot deliver a late marker. The private bridge distinguishes ordinary chunks, explicit completion and failure: unexplained sender disappearance is one fused BrokenPipe error, never successful EOF.

## Late-panic finding and bounded resolution

Pinned `leptos 0.8.22/src/suspense_component.rs:351-430` creates an isomorphic effect; its later `children.dry_resolve()` call at lines 399-405 can reevaluate a resolved child outside the body future. A panic there kills the internal effect task and leaves the Suspense completion pending. The normal body catch_unwind cannot observe it. `any_spawner 0.3.0/src/lib.rs:178-185` calls tokio::spawn/spawn_local and discards the JoinHandle. A private runtime owns those tasks but stable public Tokio APIs cannot recover their handles or enumerate/join them individually. Runtime task termination hooks and UnhandledPanic are explicitly tokio_unstable in pinned Tokio 1.54.1. No upstream/server edit or global hook was made.

Direct factory/Head/body-poll panics retain their native cause and terminate immediately. The internal-effect case terminates at the configurable render deadline; the resulting cause is a typed std::io::ErrorKind::TimedOut, while the original upstream panic diagnostic remains in the native child log. A 100 ms fixture deadline must produce the safe failure marker/error within a 600 ms outer allowance, omit completion, and release all Resource/root captures after body Drop/join. The child itself has a 15 s independent parent kill/reap watchdog. The host independently proves tighter idle deadline, disconnect and shutdown cancellation. The coordinator explicitly accepted a finite configurable deadline as a backstop and requested public-API early observation be assessed; discarded handles prevent that observation for the internal effect case.
