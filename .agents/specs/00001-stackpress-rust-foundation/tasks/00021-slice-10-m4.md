Missing Location returns the response. |

The native client disables reqwest's automatic retry, redirect and Referer behaviors; the API's tested redirect loop supplies fetch compatibility. Source Node's default fetch does not select an environment proxy, so the default adapter disables reqwest automatic proxy lookup. No API timeout, HTTPS-only switch, private-address filter or body cap is added. One fetch can include normal redirect exchanges; those are not delivery retries. Response headers resolve the send; response bodies are dropped without awaiting/draining or calling error_for_status. Cancellation drops the active borrowing future, with no detached send.

Mechanics necessities: typed config and inherited host/value budgets; static registration and Send futures; explicit immutable transport ownership; an Arc carrier for JS container identity; explicit Date/Undefined wire conversion; native reqwest HTTP(S)/TLS errors. Unsupported bytes/files/arbitrary native values require a deliberate wire representation and fail conversion. Source JS prototype/inherited-property access and isolated UTF-16 surrogate strings have no general equivalent in the Rust data model. Requested isolated surrogate properties return a mechanics error. Native HTTP transport does not claim a complete browser Fetch/CORS/CSP/port-blocking environment.

No remote server, DNS/TLS connection, proxy, socket acknowledgement, response-body drain/reuse or live redirect was exercised. The native adapter's production request/redirect algorithm ran against finite in-process metadata responses; actual reqwest network exchange remains unexercised under the no-network release. Node Request constructor cases exercise method/body normalization without sending. These evidence limits are not replaced by construction-only network claims.
