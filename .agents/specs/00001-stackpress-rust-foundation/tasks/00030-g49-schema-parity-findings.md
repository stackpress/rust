Runtime Column assertions still represent the string-required and minimum-length behavior listed above; missing Model metadata does not establish a missing runtime check. The receipt proposes comparing the common storage contract strictly and separately surfacing every metadata omission, pending coordinator/owner ruling; no expected-difference allowlist has been accepted.

The negative control changes a literal Profile.type default and the comparator detects it. Full matched/unequal comparison data and executable probe sources remain outside the repository in `/private/tmp/g49`. There is no passing full-parity assertion at this checkpoint.
