# Slice 5 Reactus, view and desktop inventory

Disposition inventory for [checkpoint decisions](slice-5-design-decisions.md). “Now” means proposed after approval, not implemented. “Later” names a proposed follow-up in that router. “Not ported” rejects a source mechanism/behavior deliberately. Every alias/re-export inherits its original owner's disposition; no TS ABI compatibility is promised. Source tests were read as contracts, not executed in sibling checkouts.

## Desktop and other interface boundaries

Electron app/window/preload/local token/HTTP runtime/menu contribution/configured route rules/build/packaging are source responsibilities, not an instruction to embed HTTP in Tauri. Now implement only a packaged main WebView and explicitly permitted local search/cancel commands; host lifecycle remains shared. Menu order/contributions, device features, configurable route grants, signing/updating/mobile are S5-F5. Reserved/incomplete protocol/update behavior is not represented as source parity. CLI/API/MCP exposure is never implied by UI registration; MCP/API feature families remain their own later framework tasks.

## Source test disposition

Every assertion in a source test file follows its named owning surface above; framework-specific constructor/JS/Node/Vite assertions are **not ported**, even where a user-visible capability is implemented now. Rendering/props/Head/asset/error tests become Rust/browser contract tests; dev/HMR/runtime import tests are S5-F6 only when a Rust equivalent is accepted. Tests are evidence of source behavior, not acceptance of source security bugs.
