# Framework admin

Generate Leptos role wrappers from the frozen schema projection and keep public drafts in one UI root. Explicit generated page adapters compose actual public query/input DTOs, with separate native registration for selected generated data handlers and compiled routes. Imports register no capabilities.

Start with [getting started](getting-started.md), then read [concepts](concepts.md). Use [customizing a component](guides/customize-a-component.md) for app plugins and the [API index](api/README.md) for signatures and limits. The [generated admin example](../../../../examples/generated-admin/README.md) exercises the real three-model schema.
