# Framework admin

**Beta:** 0.2.x is the supported release series; 0.1.x users should upgrade. The API may still change before 1.0.

Compile selected Leptos controls and page adapters from application schema metadata.
The default API uses the Typed projection; [source model UI](docs/source-models.md)
uses the original source role vocabulary and a separate portable catalog.

Start with the [developer documentation](docs/README.md). Runtime imports register
no capabilities. Applications own routes, data handlers, CSRF and permissions.
