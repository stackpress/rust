# Disclosure, navigation, overlay and collection components

Import these components and their controllers from `stackpress_framework_ui::components` (or the enabled `stackpress::framework_ui` facade). Construct controllers inside the root's Leptos Owner. One source renders SSR, hydrate and CSR; adopt native drafts before hydration when users can edit before bootstrap. Constructors reject invalid configuration instead of converting it to zero or an arbitrary first choice.

Include the opt-in `BREADTH_STYLES` beside `CORE_STYLES` and `ADVANCED_STYLES`. Styles are neutral. Dialog/drawer percentage bounds resolve against the zoom-adjusted containing block. Keep overlays initially closed for deterministic hydration. Native popover APIs are required; unsupported hosts do not get an invented modal fallback.

| Family | Contract |
| --- | --- |
| Accordion / AccordionItem | `DisclosureState` owns enabled unique choices, multiple/single and required/collapsible policy. Explicit item IDs associate buttons and retained hidden panels. |
| Details | Native summary/toggle with caller-owned open signal; early native open state can be adopted before hydrate. |
| Tabs / TabPanel | `ChoiceState` separates selection and roving focus. Manual or automatic activation and horizontal/vertical keys are explicit. Supply one panel for each immutable choice, sharing prefix/index. |
| Breadcrumbs | `BreadcrumbTrail` checks at most 100 safe links; the final item is current-page text. |
| Menu / Menubar | Enabled-only roving arrows/Home/End, bounded incremental typeahead and explicit selection callback. Menubar supplies explicit menus, with left/right transitions; it does not infer route authorization. |
| Pagination | `PageWindow` has known or unknown totals, limit 1..=100, checked offsets, obsolete-page clamping and a strict canonical skip/limit codec. The host owns navigation/history. |
| Popover / Drawer | Popover is nonmodal with native light dismissal; its connected `anchor` ID and optional in-surface `initial_focus_id` are explicit. Drawer is a native modal Dialog variant, with native inertness, Escape, focus return and the existing fallback-focus contract. `DialogMode::Nonmodal` permits background interaction and preserves unrelated background focus on closure. Native modeless close requests are enabled when Escape is allowed, with a focused-key fallback; nested dialog keys stay scoped to their nearest dialog. |
| Tooltip | Plain description text, hover/focus delay, hoverable surface and native hint-popover Escape dismissal (including hover without trigger focus). No interactive child slot. `DelayMs` caps at 10 seconds. |
| Toast | Caller-owned visibility/message, status or urgent alert, explicit dismiss and optional finite lifetime. Hover/focus pauses expiry; leaving restarts the full configured duration. |
| Table slots / DataTable | Native caption/head/body/group/foot/row/header/cell; scope, spans, stripes and sticky headers. Rowspan zero keeps native end-of-group meaning; positive spans cap at 100. TableRule is an invisible width ruler **inside a cell**, with 1..=4096 pixel width. DataTable filters literally, sorts lexically with stable ties, pages and selects checked stable keys across pages. Replacement prunes removed keys and clamps stale pages. Header buttons retain native keyboard activation with decorative sort icons and `th[aria-sort]`. The page-selection label stays accessible but visually hidden. Optional `column_layout: Vec<TableColumnLayout>` controls presentation: missing entries default to `min_width: None, wrap: true`; extra entries are ignored. `min_width` uses a 1..=4096 pixel ruler; `wrap: false` keeps compact cells on one line and explicitly configured wrapping cells retain prose line breaks. Omitted layouts preserve the previous whitespace defaults. The labelled region scrolls locally in both axes. No data acquisition or record operation is inferred. `adopt_filter` preserves an early native draft while retaining the initial SSR row tree; the next explicit filter edit/set_filter applies it. |
| CollectionFieldset / TextList / TagList / MetadataInput | App-owned typed `BoundedList` of at most 100 entries, stable nonzero never-reused keys and atomic checked mutations. Generic rows use explicit create/render callbacks; factories run outside a collection write guard. Text/metadata rows retain inline fields and named up/down/remove icon actions. Text/tag entries cap at 4096 bytes; metadata keys cap at 1024 bytes and values at 4096. Duplicate tags/metadata keys remain app policy. TagList shows plain removable chips and a separate labelled add draft; it has no chip editing/reorder controls. Enter/Add append exact nonblank text without trimming, splitting or deduplication; whitespace-only drafts stay unchanged. Existing empty strings show “(empty)”. Hidden inputs retain stable names. Empty Backspace focuses the last remove button; removal focuses its neighbour or the add input. Composition confirmation never adds a tag. |
| Combobox / SuggestInput | Query, selected machine value, active descendant and acquisition status are separate. None differs from selected empty. Immutable checked options cap at 100 and value/label at 1024 bytes. Async request tickets own loader futures; synchronous publish checks controller identity and generation. Supersession, close, disable and root disposal cooperatively cancel yielding work. There is no initial lookup or inferred endpoint. |
| Slider / RatingInput / SlugInput | Native single/ordered-pair finite range grid (at most 10,000 steps); optional integer rating including explicit zero; `RatingInput::min` defaults to zero and restricts admitted options without changing `RatingState`. Zero has a small numeric control only when admitted; positive options use decorative 24-pixel Lucide stars. Native radios retain “N of max” names, arrows/Space/Tab, cumulative fill before JavaScript and a visible Clear rating action. None remains Unrated, distinct from Some(0); verbatim slug draft plus an explicit normalization action. Slug alphabet/case policy is selected by the host; input caps at 4096 bytes. These are bounded edit controls, not M3 locale/precision/phone/date formatters. |

All public text is escaped. App validation stays app-owned; native form values are not authorization. `FieldValue<T>` retains Missing, Null and Value(false/empty/zero) separately for explicit nested editors. No schema reflection or parsing of arbitrary HTML children is used.

Overlay measurements/listeners/ResizeObserver/timers belong to the component Owner, with cleanup on close/unmount. Async loaders must yield and stay bounded: cooperative cancellation cannot interrupt CPU-bound or non-yielding code. A root-owned abort handle does not imply arbitrary worker threads may mutate reactive state; publish completions in the originating UI context.

`Theme::System` and the framework-view `system` page token are additive. Include `SystemThemeStyles` before paint (or include its trusted `SYSTEM_THEME_STYLES` in the initial stylesheet) to resolve light/dark through CSS media queries. No browser storage or initial JS media lookup is needed. Existing light/dark stylesheet bytes and defaults remain unchanged.

The shared `examples/ui-gallery` composition and its finite intercepted browser proofs demonstrate these contracts in Chromium. Packaged WKWebView, assistive-technology review and owner visual acceptance remain separate evidence.
